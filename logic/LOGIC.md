## 四诊状态机

任意顺序。缺一仍可开方/扎针，评分打折。

```
clinic_idle
  → 点病人 → patient_selected
      → 望 / 闻 / 问 / 切（可重复、可穿插）→ examining
      → 直接开治（允许）→ treatment_choice
          → 拖药成方 → formula_crafting → settling
          → 点穴 → needling → settling
      → 下一病人 → clinic_idle
```

每做完一项，只揭那一项的线索。病人不交全症状。

过程倍率：

`process = max(0.40, 1.0 - 0.12 × 缺项数 - 0.08 × 缺的主诊数)`

主诊见各病机表的 `primary_exams`。三案都把切放进主诊（脉象要进 Steam 截图）。

## 疗效评分

对证 × 过程 − 误治 − 过治 ± 快慢。映射到：未效 / 小效 / 见效 / 显效 / 向愈。

- **对证**：覆盖 `required_actions`，再加 `preferred_actions` 和药性。两条路径都能到「向愈」。
- **快慢**：发表、行气偏快；滋阴偏慢。急证用慢方不扣成误治，只影响快慢项。
- **误治**：用了 `forbidden_actions`（风寒当热清、阴虚用附子等）。罚 0.35，名次封顶「小效」。
- **过治**：药 > 8、穴 > 5、或耗正过高（风寒猛发汗、阴虚苦寒堆知母黄柏）。罚 0.12，仍可显效，但结算走「过」的文案。

结算只说身体变化（`settlement_flavor`），不报诊断名、不报方名。

## 手感约定

- 切：三种 `pulse.visual` 要能看出来（浮紧 / 弦 / 细数）。美工按 JSON 里的 `note_for_art`。
- 方：药柜拖到方剂盘，3–8 味。
- 针：在身上点 2–5 穴。
- 问：接 Qwen；失败用 `inquiry_anchor` 当模板句，保证能玩。
