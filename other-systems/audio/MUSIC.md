# 墨问岐黄 / 杏林墨问 · 配乐与互动音效（切片）

依据设定包 **`05 音乐与音效志 v1.1`**（`design-pack-v1.19/extracted/05_音乐与音效志_v1.1.md`）。  
负责：游戏音乐 · 引擎 Godot 4 · 总线 Ambient / Music / SFX

## 一句

声音要像宣纸。雨是底，古琴是墨点，切脉时旋律让开。  
琴为主，箫为辅；不走史诗管弦；不用金属 UI 音。

不是中医教材 BGM，也不是史诗国风。近邻是《Strange Horticulture》店内雨 + 极简旋律，和《Potion Craft》的小房间混响（不要大殿尾音）。乐器换成古琴、箫，材料换成木头、宣纸、瓷碗、针、印泥。

## 切片范围（本轮）

**只做医馆日间床 + 互动短音。** 志里 M00–M21 全曲表 **不是本轮**（全作后置）。  
仍无按病人整轨 BGM；切诊 Music duck 已在 Godot 侧完成。

| 层 | 何时 | 音量关系 |
| --- | --- | --- |
| Ambient 雨 | 进医馆就播，免责画面更低或静 | 底，`rain-clinic.ogg`，默认 ≤ **0.32** |
| Music 薄床 | 坐堂后极低音量；切诊再降或静 | 永远低于雨；`clinic-bed.ogg` 建议 0.12–0.18 |
| SFX | 点、拖、入药、扎针、脉、落印、风铃 | 可盖过旋律，不可盖过语音/问诊字 |

## 气质（志 v1.1）

- 留白：乐句之间要能听见雨和抽屉。
- 室内：短混响，像坐堂。
- 手做：药是拖进去的，针是点上去的，音效是材料，不是菜单哔一声。
- UI 点击 = **印泥轻捺**，不是金属咔。
- 落印成功 = **朱砂印**；失当 = **墨洇宣纸**，不要警报声。
- 特殊病人进门 = **风铃一记**。
- 倒药混错 = 多一声 **闷响**。
- 毫针 = 布与微木；禁止皮肉写实夸张。
- 不要：二胡哭腔、大编制、歌词主题曲、按病人切整首 BGM、现场音乐会录音。

## 开发负责人挂接提示（本轮新文件）

总线与进场景仍由开发负责人挂；本轮只补资源，**不改** Godot 场景/脚本。

建议 one-shot 键名（与现有 `AudioHub.play_one` 风格一致）：

| 用途 | 优先文件 | 备注 |
| --- | --- | --- |
| 通用 UI / 选病人 | **`ui-ink`** | 印泥轻捺；问诊翻页等纸面交互继续用 **`ui-paper`** |
| 特殊病人进门 | **`chime`** | 一记软风铃，室内衰减 |
| 反畏 / 配方软失败（混药错） | **`herb-wrong`** | 闷响，比 `herb-drop` 更闷更轻 |
| 结算成功路径（可选） | **`stamp-ok`** 或 `settle-3`/`settle-4` | **两条都可**：落朱砂一记作「印成」；或继续用 settle-0…4 作疗效连续谱。建议 rank 高档可叠一声 `stamp-ok`，低档不叠。 |
| 结算失败 / 失当（可选） | **`ink-bleed`** 或 `settle-0`/`settle-1` | **两条都可**：墨洇作「失当」语义；或保持 settle 连续谱。误治可 `ink-bleed` 替代/叠加更干的 settle-0。 |
| 切诊脉 | 现有 `pulse-*` | Music duck 已接；勿换整轨 BGM |
| 开柜 / 入药 / 针 | `drawer` / `herb-drop` / `needle` | 已有 |

## 锁定（勿破）

- `rain-clinic.ogg`、`clinic-bed.ogg`：**不得替换或重编码**；雨默认音量 ≤ **0.32**；床永远在雨下。
- 切诊 Music duck：Godot 侧已做。
- **无** per-patient 整轨 BGM。
- 许可：本目录合成均为 **「杏林墨问 original」/ 墨问岐黄**；禁止现场音乐会录音；非必要不引外部采样。
- 格式：Ogg Vorbis，44.1 kHz stereo；短 SFX 峰值约 −12～−6 dBTP。

## 明确不做（本期切片）

- M00–M21 全量 BGM、标题曲、歌词、角色主题
- 按病人切换整首 BGM
- 捣药/艾灸/地图笔锋/铜钱/线装书/比赛拍木
- 全部 12 脉图层（只保留切片三层）
- 穿越朝代包、药圃野外、经营层、语音旁白
