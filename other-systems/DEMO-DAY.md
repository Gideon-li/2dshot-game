# Demo 一日怎么玩（墨问岐黄）

约 **8～15 分钟** 可讲完的一条日动线。文化体验，不能替代就医。

## 推荐序（可跳步）

1. **晨诊处治** — 接一位（如阿福）→ 望闻问切 → 开方 **或** 扎针 **或** 食疗  
2. **午后药圃** — 认采一味  
3. **黄昏炮制** — 洗 / 炒 / 晒任一事（须炮制药生品不可入盏）  
4. **夜读医典** — 阁楼翻一页，领悟一个理论节点  
5. **次日开馆** — Day +1；有 pending 复诊则优先入座  
6. **复诊收工** — 看病程；观察勿药或再治

侧栏 **今日引导** 默认开，可关；打勾只提醒，不卡死顺序。

## HUD

- `Day N` + 晨 / 午 / 暮 / 夜 格亮灭与按钮灰亮一致  
- 格用尽：按钮灰 + 一句原因  
- 结算后看下一跳提示（药圃 / 炮制 / 阁楼 / 次日 / 复诊）

## 快捷

主菜单或启动可选 **Demo 一日**：新档直入诊所并开引导。

## 冒烟

`demo_day_ok`：选人→最少四诊→settle→采1→炮1→夜读1页→次日→复诊入座→consume。

## 不做

新病例、情志深度、Steamworks 上架、改 LLM 默认。
