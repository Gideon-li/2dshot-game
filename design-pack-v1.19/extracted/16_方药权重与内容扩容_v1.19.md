1.11 只写了体量、向量和四笔分，没有把节气、地域接进权重。本册就是那一页的补全：药材与成方增加时气、地气字段；覆盖分改为 C×J×T；加减仍按兼夹算。地图细则见 22，节气细则见 23。与经典冲突仍听 21。

一、1.11 仍有效的部分
体量：卷一约 80 味 / 20 方，开到约 600 味 / 500 方。字段对齐药典目录级，不抄正文。R 为病症需求，S 为方、药、穴供给。君 1.0 臣 0.6 佐 0.35 使 0.2。
对证分 M = 0.45 C* + 0.20 B + 0.25 A' + 0.10 U。B 为成方贴合，A 为加减，U 为结构。开放解仍在。反畏进不了盏（18），不在 A 里处理。
二、本册改什么：C 要乘时气与地气
1.11 的主覆盖 C 只看 S 与 R 的方向。现在结算用：
C* = C × J × T
J 是节气（旺脏、生克），T 是地域（当前区或患者籍贯）。B 不乘 J、T——经典主方的「是不是这首方」不随四季改写。时、地只改变「这首方此刻打得有多贴」。

七、算一例（写入引擎时按此对）
患者：江南，秋分，肝郁血虚。方：逍遥散原方。
C 原 81.7（与 1.12 正例同）。J=0.88（秋金克木）。T=1.00（经方）。C*=81.7×0.88×1.00≈71.9。B=73。A=0。U=90。M≈0.45×71.9+0.20×73+0.25×50+0.10×90≈68.4。仍过线，低于春用的约 73。
若加麦冬或沙参一类润燥（本案兼秋燥、不反畏）：A 原 +6～+8，M 回到 72 上下。加附子：锁或不锁视反畏，向量上与肝郁无关且热，A 负。
