文档结构一览
一、项目定位与核心体验
▣ 一句话
你不是在做一道有标准答案的中医选择题，而是在一座会呼吸的水墨世界里，用望闻问切慢慢读懂一个人，再用药性与针石给出「合理」的回应。
▣ 玩家体验承诺
《墨问岐黄》首先是一款「以诊疗为戏剧」的养成探索游戏，其次才是中医科普。玩家从一名什么都不会的少年学徒起步，在「杏林小筑」跟随苏问舟先生，把阴阳五行、四诊、本草、方剂、针灸，从墙上的字变成手上的本事。病人不会把证型写在脑门上：你要看神色、听气息、问生活、切脉搏。同一种病，樵夫、绣娘、书生、胡商会说出完全不同的话；下一次再遇见类似的证，对白也不会重复——因为对话由大模型按「病例卡」现场生成，但症状锚点始终锁定。
治疗没有唯一解。桂枝汤能走的路，有时艾灸也能走；同样补气，黄芪与人参的缓急不同，病人康复曲线就会不同。系统给的不是对错，而是「快、稳、准、温」四维评价，以及病人几天后的回访。当你在五方山水间采药、开馆、收徒，医名会写进「杏林名录」。最终，一卷残破的《岐黄绘卷》会带你走进历史里的病——那是可后置的资料片层，不挡主线。
▣ 核心循环（30秒版）
清晨开馆 → 接待或出诊 → 四诊收集线索 → 辨出证型（可部分正确）→ 选方 / 加减 / 针灸 / 食疗 / 情志疏导 → 病人离开并进入「病程时间」→ 白昼去山野市集采药辨药 → 黄昏炮制、抄方、教习学徒 → 夜读医典解锁理论节点 → 季节更替，新的时令病与地域开放。
▣ 成功标准（体验层）
一个从未接触中医的玩家，在第1小时结束时能说出「寒热虚实」四个字的直觉含义；在第5小时能独立完成一次完整四诊而不依赖弹出提示；在第15小时会主动为同一张方做加减，而不是背标准答案。文化向玩家则会在药柜、对联、市声、节气里感到「这是中国的」。
二、设计支柱与禁忌
▣ 四根支柱
▣ 明确不做
不做恐怖医院、不做真实人体解剖暴露、不做「输入症状就弹出标准方」的题库游戏、不做付费才能治好病的良心绑架。不把任何单一方剂神化为万能药。不对真实疾病给出可替代就医的承诺——每次进入诊疗都会有一句克制的声明：此为文化与逻辑推演，不能替代现实医疗。
▣ 真实感与游戏感的分寸
药性、归经、常见证型、经典方名尽量尊重通行教材与《中药学》《方剂学》的共识，但剂量、煎法、毒性处理全部游戏化：用「份、钱、火候、配伍灯」而不是让玩家背克数。有毒药物（附子、马钱子等）只在高阶关卡以「炮制小游戏 + 明确警告」出现，且有安全替代路径。儿童、孕妇病例会有额外约束标签。
设计备忘 大模型 API Key 只放在服务端环境变量，禁止写进客户端、文档和版本库。需求稿里的密钥建议立刻作废轮换。
三、美术、镜头与音乐风格
▣ 总风格：暖色水墨淡彩 + Q版人物
以需求附图为基准：不是冷寂的纯黑白文人画，而是「宣纸底色 + 赭石木器 + 花青远山 + 朱砂点睛」的暖色淡彩。人物头身约 2.5～3 头身，眉眼清、手部可做细动作（诊脉时两指按寸关尺）。场景有体积，但边缘用枯笔和飞白，远景留白。光从格子窗斜进来，尘埃是细小的墨点。
风格锚点：杏林小筑诊室。药柜抽屉、脉枕、吊挂药把、对联「医者仁心 / 悬壶济世」为不可替换的视觉符号。
▸ 色彩规范
▸ 镜头与转场
大地图是可平移的长卷：笔锋从右向左刷开，露出下一座山。进入建筑用「门轴推开 + 一层薄宣纸揭起」。诊脉时镜头缓推到脉枕，腕下出现一层半透明的水墨波形。治疗成功，朱砂小印落在病案角上；失败或延误，墨滴洇开一圈，但不做血腥表现。
▸ 角色与场景绘制原则
角色：单线平涂 + 淡墨体积，面部少阴影，衣服用低饱和固有色。老人皱纹用干笔，孩子用圆润短线。场景：近景家具结构清楚（可点击），中景吊药、窗外蕉叶，远景只留一抹山影。UI 像册页和药柜：标签是小楷，按钮是印泥色的椭圆印章。
▣ 音乐与声场
整体是「琴为主、箫为辅、偶有埙与铃」。不走史诗管弦，避免游戏感过强的 Percussion。每个地域有一个调式中心，对应五行。
▸ 音效原则
诊脉：不同脉象对应不同的「指下音」——浮脉如丝线掠过宣纸，沉脉如石落入深井，数脉是略快的木鱼，迟脉是远寺的钟。开抽屉、倒药、捣药、艾灸燃起，每一种都要能闭眼辨认。UI 点击是印泥轻捺，不是金属咔哒。
四、世界观与历史层
▣ 世界的两层
表层世界名为「墨州」。它不是严谨的历史切片，而是把江南市镇、川峡药谷、北地边关、岭南湿热压缩在同一张可展开长卷里的文化地理。节气运转，五行在大地上看得见：春日青木林的芽会按「生」的方向去催发相邻的黄土原，夏天赤焰谷的热浪会「克」向西方的素金岭……这既是美术变化，也是系统修正。
里层世界是「绘卷层」。传说黄帝与岐伯问对的内容，并未全部写进人间的书，而封在一卷会呼吸的墨画里。谁能以医心而非贪心打开它，就能短暂走入某个朝代的一场病——张仲景灯下写伤寒、孙思邈入山、李时珍访药、叶天士在江南看温病。这一层默认作为后期模式 / 资料包，主线只先露出卷角。
▣ 开局设定（可在角色创建时微调动机）
默认故事：玩家姓氏自选（默认「江」），名由玩家填写或随机（默认「晚」），故以「江晚」称呼。江晚的故里在一次春瘟里塌掉了半座村子。郎中们或走或逝，江晚带着一册缺页的《汤液歌诀》和一封没有署名的荐书，来到墨州青石镇的杏林小筑。荐书只有一句话：「可教。先让他洗手、研墨、认药，再让他碰人。」
苏问舟收下江晚，不是因为荐书上的字，而是因为江晚进门时先看了药柜上落的尘，又伸手去扶差点摔倒的老者——「眼和手还在，心还没冷。」
▣ 世界规则（给玩家的「玄学」必须服务于医理）
墨州有一种叫「证纹」的现象：当一个人的气血长久失衡，腕间、舌面或窗纸上会浮出极淡的纹样。玩家初期看不见，随着「望诊」技能提升，纹样会从装饰变成可读的提示。它不是外挂透视，只是把望诊经验视觉化，可在设置里关闭「证纹显示」以增加硬核。
时令是最大的环境 Buff。惊蛰后风证变多，夏至后暑湿，秋分后燥咳，冬至后肾与关节。乱投寒凉或温热，会在评分里被明确指出「逆时」。
五、人物设定全集
▣ 可创建主角 · 江晚（默认）
▣ 师门与据点人物
▸ 苏问舟 · 杏林小筑主人 · 导师
约五十二岁，身瘦，须短而整齐，常年一件洗旧的青灰直裰。年轻时走遍五方，中年因一桩误判的「真寒假热」失去过一位至交，从此把「慢」当成医德。教学方式是只问不答：江晚说「是风热」，他只回「那他为什么还要盖三床被子？」直到玩家自己改口。
关键秘密（卷三末揭开）：荐书是苏问舟自己让故人写下的。春瘟那一年，他没来得及赶到江晚的村子。收徒是还愿，也是赎。
▸ 小荷 · 药童 / 后期可收为第一位学徒
十二三岁，镇上游医的遗孤，认药极快，认字不快。说话像炒豆。负责把药柜抽屉变成玩家的图鉴入口。与玩家的关系从「抢研船」到「出诊时替你看门」。好感度高时会偷偷把难找的药苗位置画在纸上。
▸ 阿桂 · 药农
四十岁，背微驼，手上永远有泥。是青木林与黄土原的活地图。教玩家「不是书上写生在阴坡就一定在阴坡——今年雨斜着下」。可成为采集伴侣，减少遇险。
▸ 陈半仙 · 街头走方医
花白山羊胡，招牌比医术响。不是反派，是镜子：他用噱头让人安心，有时歪打正着，有时误人。主线里会与玩家抢一单「县衙急症」，失败教会玩家沟通，成功教会玩家谦虚。可在支线被收服为「巡回代诊」——评分上限较低，但能帮玩家照看低危复诊。
▸ 周绣娘 · 镇中绣坊主事
二十八岁，寡，有一女。第一位让玩家明白「情志也是病」的人。主线卷一的收束病例：表面是失眠头痛，里层是悲与郁。治不好她，苏问舟不会让玩家出镇。
▸ 赵捕头 / 县丞陆衡 / 胡商萨米尔
分别承担「外伤与瘀」「饮食劳倦与应酬」「水土不服与香药交流」。萨米尔会把西域药材带进图鉴，是后期解锁「外来药性对照」的钥匙人物。
▣ 病人原型库（供 LLM 套皮）
每个出场病人都从下表抽取「身份 × 年龄段 × 地域 × 性情 × 隐瞒倾向」，再叠一张隐藏证型卡。对话风格锁在身份上，症状锚点锁在证型上。
▣ 对手与阴影
「白仲」：行走五方的年轻医士，技在苏问舟与江晚之间，信「快刀」。他不是恶人，但会把复杂证压成一张方，疗效来得猛、去得也猛。卷四时疫中，白仲的方案能立刻压住热，却留下大虚。玩家要在「救这一夜」和「救这一季」之间做选择——两条路都能推进剧情，名录评价不同。
六、主线剧情五卷
主线以「卷」为结构，对应长卷的五次展开。每卷结束有一次「大案」和一次理论考核（考核也是戏，不是试卷）。支线可穿插，不写死顺序，只锁必要前置。
▣ 卷一 · 洗手研墨（约 3–5 小时）
▸ 戏剧任务
让玩家习惯医馆的手感：认十味药、学会望神与问寒热、第一次把脉只要求分辨浮沉与迟数、第一次给周绣娘一个「不完美但安全」的方案。
▸ 节拍
第一日：进门、洒扫、被小荷嘲笑把甘草当成黄芪。苏问舟让江晚把药柜七十一个抽屉的标签抄一遍——游戏化为「分类小游戏」：按四气、五味、归经把药材拖进柜格。抄完，苏问舟才准许坐到脉枕对面。
第三日：第一个病人是阿桂的儿子，过午不食、舌淡、说「腿软」。玩家若直接补药，苏问舟会拦：「先问他中午在哪。」真相是孩子把午饭换了话本。本关教学：问诊比开药重要。正确处理是食疗 + 轻健脾，不是大补。
第七日：周绣娘。她说头痛，实际是「睡到三更必醒，醒后胸口像压着绣架」。问到亡夫忌日才会说真话。切脉得弦细。玩家可用酸枣仁汤思路、或针灸神门三阴交、或只先处理「晚间独自刺绣」的生活调整。只要抓住「郁 + 血虚」中的一面并保护胃气，即可过关。苏问舟在案后写下：出镇许可。
▸ 卷一结束动画
夜雨。苏问舟把那封荐书在灯上烘平，江晚看见自己村子的旧名。苏问舟只说：「先成为配得上这封信的人。」琴声第一次完整响起。
▣ 卷二 · 青石十二病（约 6–8 小时）
▸ 戏剧任务
在青石镇独立接十二个典型证：风寒、风热、暑湿、食积、气郁、血瘀轻证、脾虚湿困、阴虚燥咳、阳虚畏寒、湿热下注、外伤肿痛、小儿惊啼。每治好一类，图鉴亮一枚「证印」。
中段插入陈半仙抢案：县丞陆衡宴后剧痛。陈半仙要开巴豆。玩家若辨出是「食积兼寒」，用保和丸思路或温和消导即可；若跟风用峻下，陆衡当夜泄虚，剧情仍可救回，但会触发「公堂问责」支线，丢失部分名望。
卷末：镇口来了萨米尔，水土不服，皮肤与胃肠同时出问题。本关教学「同一人可有两证，要分主次」。
▣ 卷三 · 五方开卷（约 8–10 小时）
苏问舟将《岐黄绘卷》的一角摊开，五方山水从墨里浮出。玩家必须亲自走一遭，才能把「五行」从口诀变成气候、土壤和人的性格。
青木林：风证、肝郁、跌打损伤。阿桂同行。采集教学深化：采时、部位、老嫩。林中有一桩「怒伤」——猎户与兄弟反目，针药之外要做一次调解小游戏。
赤焰谷：暑热、心悸、疮疡。白仲初次正式交手，他用大剂寒凉退热，病人第二天腿软。玩家若只用寒凉，评分中等；若清热护阴或透暑，评分高。
黄土原：湿困、脾胃、妇人带下（处理需得体，对话可回避直接器官描写，用「下身困重、绵绵」等）。小荷在此认字过关，可收为学徒。
素金岭：秋燥、咳喘、皮肤皴裂。出现矿伤与肺的隐喻。解锁部分金属针具。
玄水泽：肾虚、水肿、骨痹。冬季副本。苏问舟的至交墓在泽边，卷三秘密在此揭开。江晚可选择原谅或追问，影响卷四苏问舟是否亲自上阵抗疫。
▣ 卷四 · 青石时疫（约 4–6 小时）
一场「寒从湿来、热从口出」的时疫。不是历史某场瘟疫的复刻，而是把「传变」做成关卡：同一家族里，祖父是寒湿、孙子是热毒、母亲是劳虚感邪。玩家要建临时医棚、分配学徒、管理药材库存。
关键选择：接受白仲的「大剂速清」以降低当晚危重人数，或坚持辨证分流让总死亡（游戏用「恶化离镇」表示，避免死亡计数器直白化）更少但前两夜更难。两种结局都能进入卷五，名录称号分为「急先锋」与「稳后方」。
情感高潮：周绣娘的女儿高热。若卷一把周绣娘的信任做满，她会把孩子完全交给你；否则会听陈半仙的符水。这是「以前的床边态度会在后来变成系统」的回收。
▣ 卷五 · 卷角与远行（约 3 小时 + 无尽）
时疫退后，绘卷自己展开一寸。苏问舟不再收江晚为徒，而改为同道。玩家获得「开馆权」：可在五方设分铺、可上「杏林名录」排行、可接随机世界病例（LLM 无限生成，受地域与季节约束）。
绘卷深处露出四个模糊的年号影子——建安、贞观、万历、乾隆——提示穿越模式。主线正式落幕词：
医名不是刻在石上的。是刻在下一个还愿意把手腕放上脉枕的人那里。
七、地图与场景清单
▣ 大地图结构
一张可左右展开的水墨长卷，中央是青石镇，五方按东木、南火、中土、西金、北水布置，中间用江、驿道、栈道连接。未解锁区域是淡墨轮廓，解锁时被一层水晕染开。移动消耗「时辰」而非体力条，以强化中医时间观。
▸ 杏林小筑内部房间
门厅（患者等候、小荷接待）、诊室（核心）、药房（柜、秤、碾）、炮制院（炉、晒、洗）、厢房（玩家休息、换装、日记）、阁楼（医典、绘卷、成就）、后院（药圃，可种植已识别的药）。每个房间都有 8–15 个可互动物件，用于世界感和少量彩蛋。
▸ 天气与节气对地图的改写
雨天青木林滑，采集失败率升、湿证病人增。晴天赤焰谷可晒药，缩短炮制。霜降后玄水泽结薄冰，出现骨痹高峰。春节、端午、重阳有主题摊位与时令方教学（端午挂艾、重阳菊花）。
八、核心玩法总览
▣ 一日时辰
一天分五个行动格：晨、午、午后、暮、夜。接一个普通门诊耗 1 格，复杂大案耗 2 格，出镇旅行按距离耗 1–3 格，炮制与夜读占夜格。学徒解锁后可代行「低危复诊」和「定点采集」，等于把时辰放大。
▣ 三大活动柱
▣ 失败是软的
不会「Game Over 读档」。处治失当会导致：病程延长、名望微降、病人转投陈半仙、学徒信心下降。危证有「恶化离镇」——叙事上是去了更大的医馆或回乡，不展示死亡画面。只有极少数主线大案失败会进入「补救夜」：苏问舟接手，玩家降为助手，但仍能学到正确思路。
九、望闻问切与大模型
▣ 设计原则
症状不对玩家坦白。开局只有：外貌、步态、一声咳嗽或一句「大夫，我难受」。其余全部靠四诊。大模型负责把「病例卡」演成一个具体的人，不负责发明新的主证。脉象、舌象、基础体征由系统给出确定性数据，避免模型幻觉导致无法辨证。
▣ 病例卡结构（每张病人一张）
▸ 望
点击病人全身：神、色、形、态。可看舌（伸舌小游戏：光线、角度）。初期信息少，升级后能看出「面如敷金」「目眶暗」等。证纹开关见世界观。
▸ 闻
听声息与嗅气味。做成短音频识别：喘息、鼻音、口气（酸腐/腥）。无语音环境则用文字+波形。
▸ 问（LLM 主场）
玩家可用：快捷问句模板（寒热、汗、头身、二便、饮食、睡眠、情志、经带、旧病、职业）+ 自由输入。自由输入经安全过滤后交给模型。模型必须：1）不直接说证型名；2）不一次把主症说完，除非玩家问到；3）按性情决定绕不绕；4）每次生成改写措辞；5）小孩答感官，老人爱回忆，商贾问工期。
系统提示词骨架（节选，需服务端保管）：你是病例卡中的病人，不是医生。只根据身份说话。主症锚点是真的，但你不会用医学词。若玩家问与病无关的事，用符合身份的方式岔开，并可在两句后轻轻带回身体感受。禁止给出「你该吃什么药」。同一锚点每次换比喻。语言跟随界面语言。
▸ 切
脉枕小游戏：把食指、中指、无名指放到寸关尺，按浮中沉三层。正确脉象以波形+形容词给出（「如按琴弦」「来盛去衰」），不直接写「弦脉」直到玩家夜读解锁该名词。可重复切，但占用少量时辰压力（病人不耐烦）。
▣ 辨证板
四诊后，玩家在「病案纸」上拖拽标签：部位（表里）、寒热、虚实、阴阳，再选脏腑或六淫。允许部分正确。系统用「匹配度」而不是对错灯。提交后才能处治。若匹配度过低，苏问舟或小荷在前期会咳嗽提醒；后期没人救场。
十、本草、方剂与针灸（开放解）
▣ 药不是图标，是一组向量
每味药有：四气、五味、归经、升降浮沉、有毒否、时令加成、炮制态。处治时，系统不比对「是否等于标准方」，而比对「你给出的药性向量与证型需求向量的夹角」+「有没有明显十八反 / 十九畏 / 逆时 / 伤胃」。夹角越小，主分越高；配伍有君臣结构再加分；有小毒未炮制则扣安全分。
▣ 三条合法路径
允许组合。例如周绣娘：针神门 + 酸枣仁一两味 + 劝她忌日不要承绣，是高分稳妥解；只劝说也能慢慢好，评「温」高「快」低；大剂重镇安神则「快」高但次日头昏，「稳」低。
▣ 评分四维
综合分写入名录。排行榜默认用「准×0.4 + 稳×0.3 + 温×0.2 + 快×0.1」，强调医德与准确，不鼓励无脑追速度。可在设置提供「赛事权重」供竞技房改权重。
▣ 本草与方剂含量（初版建议）
初版收录常用饮片 80–100 味（覆盖四气五味与主要归经），成方 30–40 首（桂枝汤、麻黄汤、银翘散、香苏散、保和丸、四君子、四物、逍遥、六味、金匮肾气、酸枣仁汤、血府逐瘀、藿香正气等），穴位 20–30 个常用穴。图鉴以「认药小游戏 + 口诀 + 实物图」教学，不要求玩家背全。
十一、成长、学徒与经营
▣ 熟练等级不是战力，是权限与手感
▸ 学徒系统
小荷之后，可收阿桂之侄（采集专精）、哑巴针师（针灸专精，用写字交流，温暖支线）、萨米尔的翻译学徒（外语病人加成）等。每位学徒有精力条与风格。派遣规则：低危复诊、定点采集、坐店看铺。教学小游戏能提升他们「不自作主张」的概率——这是把「带教」写成玩法。
▸ 采集与配方便利
等级提升后：地图出现药苗微光、阿桂可标记高产点、成方一键配齐仍允许加减、炮制可「置半日自动完成」。永远不做到「一键治病」。便利的是劳动，不是判断。
▸ 轻经营
医馆有「清誉、库存、铜钱、疲劳」。铜钱只用于补货、修缮、捐庙、给学徒发月钱，不卖数值实力。看病可免可收，收得太狠温分下降。节日免费义诊换名望。
十二、地域解锁、排行与穿越
▣ 解锁节奏
卷一锁镇。卷二镇内十二证印集齐 8 枚可出近郊。卷三按主线任务逐个打开五方，允许非线序：先去赤焰谷或先去玄水泽都可以，但时令会惩罚逆季旅行（冬入谷中暑低，但采集差）。卷四时疫强制回镇。卷五全图常开。
▣ 杏林名录（排行榜）
上线后按区服 + 好友 + 世界。展示称号、四维雷达、代表病案（玩家可选择匿名）。反作弊：病例卡种子服务器生成；自由输入只影响对话，不影响隐藏证型。定期「时令赛」：本周全服同一张困难卡，比准与稳。
▣ 穿越模式（资料片框架）
入口：阁楼绘卷。每次穿越是一个「有起止的历史病案副本」，不是开放世界。玩家仍用自己的四诊，但药材库被替换成该时代可得之物（没有后期才入药的品种）。结束时带回一页「可装进夜读」的理论。
穿越里遇到的「名医」不收玩家为徒，只做一夜同行，避免历史人物被写成工具人。对话要克制，偏问对，不偏膜拜。
十三、道具、界面与本地化
▣ 关键道具
▣ 界面
主界面即医馆透视：点人、点柜、点门。病案是一张宣纸，四诊记录自动以小楷落下。处治是药柜拉开，药材以卡片拖入药盏。对话是左下角立绘 + 手写体，自由输入在底部。多语言切换时，对联、牌匾提供「原文 + 译文」开关，避免把「悬壶济世」硬译成失去文化的口号。建议英译保留 Hanging the Gourd，日译「壺を懸けて世を済う」。
▣ 多语言

十五、示例关卡与完整对白（可进表）
▣ 样章 A · 卷一第七日「绣架压胸」
场景：杏林小筑诊室，午后。窗外蝉尚未起。药柜抽屉半开。周绣娘坐在脉枕对面，背挺得太直。小荷在门厅绊了一下，被苏问舟用眼神按下。
▸ 开场（系统，非 LLM）
周绣娘：（点头，声音很轻）先生外出了？……那就拜托小大夫。我睡不好。头也沉。做活做到一半，针会停在手里。
【望】神：尚可，但目光不欲与人对。色：唇偏淡，眼眶青。形：肩背僵。舌：淡，苔薄。
▸ 问诊示例（LLM，同一锚点的三次不同说法）
玩家问「怎么睡不着？」
生成例1：（要强）哪里是完全不睡。只是一闭眼就像还坐在绣架前，耳边有线绷紧的声音。等到外头打三更，人才像从水里被捞起来。
生成例2：（绕）夜里什么都安静，安静得能听见隔壁猫走瓦。我便想：明日那朵牡丹的线还够不够。想着想着，天就白了。
生成例3：（被问到亡夫忌日后才给的真句）他忌日那天我多熬了两支蜡烛。不是为了赶工。赶完也没人看。我只是怕屋子太黑。
【切】弦而细，两尺弱。系统形容词：如按琴弦，细得要用心才觉得还在。
▸ 合法处治三例
高分稳妥：辨证「血虚肝郁、神不守舍」→ 酸枣仁、知母、茯苓、川芎、甘草（酸枣仁汤思路）+ 神门、三阴交 + 劝其忌日前三晚不承急活。预计五至七日回访明显。
中分偏慢：只开两味安神 + 食疗红枣莲子 + 生活劝说。十日后方显。温分高。
中分偏快不稳：重用龙骨牡蛎一类（游戏里以「重镇药」标签出现）。当晚能睡，次日头昏，绣活出错，稳分低。
低分伤正：当实热清泻。次日泄、更虚。触发苏问舟接手。
▸ 回访（第七日后）
若温分高：她送来一副绣了艾叶的帕子，「不是诊金，是怕你们柜子上落灰。」若只追快：她说「药很猛，我有些怕」，不再介绍邻居。
▣ 样章 B · 随机病人生成逻辑演示
种子：素金岭 + 秋分 + 原型军卒 + 证型「凉燥伤肺」。锚点：干咳少痰、咽痒、皮肤皴、脉浮涩。LLM 不得说「我是凉燥」。军卒会说「嗓子像被砂石打过」「营里都笑我像叫的鸦」。若玩家只润肺不散凉，快分中、准分中；若温润得法，四维均衡。
