## 1. 一句话

处治选情志 → 三拍：倾听（3 选 1）→ 疏导卡 1～2 张（池 6）→ 可选起居约定 → `settle("emotion", …)`；可从窗下茶侧进，也可纯 UI。

教学锚：**沈清荷 / `ganyu_qizhi`**。手感：听、映、缓；不做情缘。

## 2. 推荐路径（主）：纯 UI

与开方托盘 / 膳盏同级：点 `ACTION_EMOTION` → 全屏/半屏疏导层 → 交卷 `settle("emotion", …)` → 回诊室。

| 镜头 | 中心 | 用途 |
| --- | --- | --- |
| `CAM_EMOTION` | **(1280, 700)** 或沿用 `CAM_RESULT` | 安静坐堂；疏导层盖 UI，不必新 World |
| 退出 | 回进入前相机（多为 `CAM_HERO` / `CAM_ASK`） | |

### UI 位框（1920 设计宽）

```
顶栏：四诊 / 处治钮（ACTION_EMOTION 与开方、针灸、食疗并列）—— 疏导层勿遮顶栏
┌──────────────┬─────────────────────────────┬────────────┐
│ ① 倾听 3 选 1 │  ② 疏导卡池 6（选 1～2）      │ ③ 收束可选 │
│ 复述贴锚      │  图标 72～96                 │ [提交疏导] │
└──────────────┴─────────────────────────────┴────────────┘
```

| 区 | 建议 |
| --- | --- |
| 倾听 | 左列宽约 360；三卡单选，不点破证型名 |
| 卡池 | 中区 2×3 或环心六向；图标 72～96 |
| 收束 | 右列一句起居约定（可选）+ 提交 |
| 避让 | **不挡** 望闻问切顶行；不挡返回；**不画脉波**；不盖 `CAM_HERO` / L5 / `pulse-overlay` |

给「坐下来听一听」进场感；点后仍打开同一疏导 UI。置 **西侧窗下**（窗1 一带），与东侧 `STATION_FOOD` 对称分开。

| ID | 位置约 (x,y,w,h) | 半径 | 说明 |
| --- | --- | --- | --- |
| `Area_窗下茶侧` / `STATION_EMOTION` | **(560, 480, 200, 180)** | 90 | 坐堂桌西、窗1 下：小茶案+盏；安静倾听角 |

| 已锁 | 位置 |
| --- | --- |

| 病人椅 | `(1040, 590)` |

切入时可微推 `CAM_EMOTION`：**(640, 540)**（窗下茶侧特写），打开 UI 后也可切回 `(1280, 700)`。
