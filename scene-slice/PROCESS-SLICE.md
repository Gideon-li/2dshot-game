## 1. 一句话

黄昏从药房/诊室侧门进炮制院：水盆洗、炉上炒（火候）、晒架翻晒，三工位并列；做完回托盘，未炮制的须炮制药不能入盏。

## 2. 平面（世界 2560×1440）

原点左下。英雄镜头裁 1920×1080。

```
Y=1440 ── 北廊墙 + 匾「炮制院」────────────────────────────────
        │  灯笼 / 漏窗装饰                                      │
Y=1000  │   ┌洗工位┐     ┌炒工位┐     ┌晒架·可点┐             │
        │   STATION_WASH STATION_FRY  STATION_DRY               │
Y=700   │ ══════════ 石板主径（可走）══════════                 │
Y=320   │  [门·回药房/诊室]                    陶罐堆(装饰)     │
Y=0     └─ 西门 DOOR_PHARMACY ───────────────────────────────┘
          X=0                                              X=2560
```

动线：
1. **`DOOR_PHARMACY`** ↔ 诊室/药房（角色开发定落点；建议挂在百子柜旁或诊室东侧小门）。
2. 点 **洗 / 炒 / 晒** → 对应小游戏 → raw→processed。
3. **晒**（V128）：`STATION_DRY` 可点；切入 `CAM_DRY`；翻晒主动操作，不是纯挂机条。

可走区：石径宽约 180–220 px。炉台、水盆内、晒架底座不可走。
