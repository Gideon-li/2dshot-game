# 《墨问岐黄》V127 · 次日开馆入口（诊室空闲）

日期：2026-09-08  
依据：`DEV-TASKS-V127.md`  
范围：诊室 **`clinic_idle`** 态挂「次日开馆 / 过一日」入口。不改大地图；不挡四诊。

参考：`scene-slice/next-day/NEXT_DAY_LAYOUT.png`（副本 `ui/next-day/`）。

---

## 1. 何时可见

| 条件 | 显示 |
| --- | --- |
| `fsm_state == clinic_idle` | 显示 `NEXT_DAY` 入口 |
| 有病人在诊 / examining / 开方 / 针灸 / settling | **隐藏**（避免误点跳日） |
| 结算页 | 可另放同功能按钮（角色开发）；场景以诊室空闲为主 |

点击：`play.day += 1` → 按 FIFO 拉起至多 1 个到期 `pending_revisits` → 复诊入座。逻辑归 GameFlow；场景只锁位置。

---

## 2. 推荐：HUD 按钮（主入口）

挂在诊室 `UI/Hud` 空闲码头（现有小荷/回访文案列下方或右下）。

| 项 | 值 |
| --- | --- |
| 控件名 | `Btn_NextDay` |
| i18n | `NEXT_DAY`（文案「次日开馆」；英/日另键） |
| 设计位置（1920×1080 HUD） | 右下安全区：`offset_right=-24`, `offset_bottom=-24`；按钮约 **160×44** |
| 锚点 | bottom-right |
| 层级 | 与空闲文案同列，**低于**任何四诊/开方条；idle 时四诊行本就不在，仍预留顶栏 56 px 勿占 |

**禁止**：全屏模态挡门；盖住脉枕/病人椅世界热区的点击（HUD 应用 `mouse_filter` 仅在按钮矩形）。

---

## 3. 可选：南门世界热区（副入口）

与「次日开门」语义一致，给手柄/探索手感。

| 项 | 值 |
| --- | --- |
| 热区 id | `Area_次日开馆` → hotspot `"next_day"` |
| 位置 | 南门洞旁，约 `(80, 40, 220, 360)` 门框内偏下可点条，或单独 `Rect2(200, 280, 120, 80)` 门栓牌 |
| 半径 | 80 |
| 可见 | 仅 `clinic_idle`；门上挂小木牌「次日开馆」美工可选 |

与现有 `Area_南门`（入场/下一位）区分：空闲无病人时南门可兼作 next_day，或木牌独立热区避免和「下一位病人进门」冲突。推荐 **独立木牌热区**，南门仍留给病人进场。

---

## 4. 避让（不挡四诊）

四诊按钮在问诊 HUD 顶行（望闻问切，约 y 顶栏下 40～56 px 高）。次日开馆：

- 只出现在 **clinic_idle**
- HUD 主按钮钉 **右下**，远离顶栏四诊带
- 世界热区在 **南门**，远离坐堂桌/脉枕 `(920,600)`、病人椅 `(1040,590)`、调剂台、针灸榻
