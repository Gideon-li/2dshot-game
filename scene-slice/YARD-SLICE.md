## 1. 一句话

午后从诊室后门进杏林小筑后院：三块药床可辨可采，走石径回诊室；右侧山径只做短 stub，不进大地图。

## 2. 平面（世界 2560×1440）

原点左下。英雄镜头裁 1920×1080。

```
Y=1440 ── 北墙「百草庭」匾 + 两樘漏窗（装饰，不可走）──────────────
        │  盆景架 / 灯笼                                         │
Y=1100  │     ┌床A┐        ┌床B┐        ┌床C┐                   │
        │     采集热区      采集热区      采集热区                  │
Y=780   │ ══════════ 石板主径（可走 U/一字）══════════            │
Y=520   │  井/石台(装饰)     小工作台(装饰)     晾药架(装饰)        │
Y=280   │  [门·回诊室]                              [山径 stub]   │
Y=0     └─ 西门接诊室 ───────────────────────────── 东口可选 ────┘
          X=0                                              X=2560
```

动线：
1. **西门 `DOOR_CLINIC`** ↔ 诊室（建议接到诊室北墙后门，或南门旁的「后院」交互；角色开发定节点名，场景锁热区）。
2. 石径 → 点床 A/B/C → 识别 UI（美工）→ 采入库存。
3. **东口 `PATH_HILL`（可选）**：一小段石阶 + 绿坡剪影。点了可播一句「今日只采到药圃」或进同一场景右侧更远 200 px 的空镜，**不加载五方地图**。

可走区：石径带宽约 180–220 px。床体、墙根、井台不可走。

---

## 3. 采集热区（2～3 个，本包锁 3）

每个热区是一块床，**床上可刷多味药**（逻辑表 `scene_spot`），场景不写功效招牌。

| ID | 位置约 (x,y,w,h) | 半径 | 用途 |
| --- | --- | --- | --- |
| `SPOT_A` | (420, 900, 360, 220) | 120 | 采集床 A。建议挂：桂枝 / 生姜 / 菊花 一类「形色分明」 |
| `SPOT_B` | (1100, 900, 360, 220) | 120 | 采集床 B。建议挂：白芍 / 甘草 / 当归 |
| `SPOT_C` | (1780, 900, 360, 220) | 120 | 采集床 C。建议挂：柴胡 / 白术 / 茯苓 / 麦冬 等 |

进出口：

| ID | 位置约 | 半径 | 用途 |
| --- | --- | --- | --- |
| `DOOR_CLINIC` | (160, 200, 200, 280) | 90 | 回诊室 / 从诊室进入药圃的落点旁 |
| `PATH_HILL` | (2320, 360, 180, 260) | 80 | 可选山径 stub；无第二张大地图 |

床面标签：**只可放药名木牌或空牌**，由数据驱动。禁止「清热解毒」类功效条（那是百科，本期不做）。

一床可对应多味：玩家点床 → 逻辑弹出该 spot 未采完的一株 → 走识别；识别成功才采。

全部 16:9。不要 3D 绕转。

| --- | --- | --- |
| `CAM_YARD` | (1280, 780) | 默认探索 / 商店或教程可截一张药圃全景 |
| `CAM_SPOT_A` | (600, 920) | 辨认时微推到床 A |

| `CAM_SPOT_C` | (1960, 920) | 床 C |
