# 《杏林墨问》垂直切片 · 场景包（一座水墨医馆）

日期：2026-09-02  
**画风锁（v1.19）：明快 Q 版，对齐 `ui/art-anchor-clinic.png`。** 暖木器、药柜、窗光落脉枕。圆角萌态。不是写意文人；水墨不再是硬约束。切片不扩大。  
空间、六台镜头中心点、交互半径不变。分层：`ui/layers/` 与 `scene-slice/layers/`。

范围：单一室内。坐堂 + 药柜。药圈压成窗沿/天井条，不是第二张地图。  
引擎假设：Godot 4，2D（可 2.5D 斜俯，禁止 3D 轨道）。  
读者：场景美术（出图）· 角色开发（碰撞/点击/Y-sort）· 截图负责人（Steam 五张）。

本包只锁空间、家具、镜头、光、图层。角色、UI、脉象可视化本身、免责声明文案不在本包。

## 1. Steam 第一张一句话

一座萌态厅堂：圆角坐堂桌、胖柜、半开的花窗2往脉枕上落一束淡青光。Q 版可爱水墨、淡彩宣纸 `#F7F0E4`。家具圆润，不是写意文人，不是像素，不是空山水。

## 2. 平面（单一室内）

世界坐标：原点在画面左下。设计分辨率 **2560×1440 px**（1× 线稿）。英雄镜头裁 **1920×1080**，左右各留约 320 px 给前景墨渍/悬药，避免截图贴边。

角色站立身高约 280–320 px。家具按「腰线 ≈ 坐着的病人胸口」画，保证诊脉手和抽屉都在 1080p 里可读。

        │                          [CAM_FORMULA]                    │

动线（Potion Craft / Strange Horticulture 只借「一张房里把工作台排满」，不借画风）：

1. 南门进 → 候诊凳（点选病人，半径 90 px）
2. 病人落到坐堂南椅 → 望（花窗光 / 伸舌）→ 闻（香炉）→ 问（CAM_ASK）→ 切（脉枕）
3. 治疗二选一，都在同一栋里：东柜拖药到调剂台 **或** 西榻点穴
4. 结算：CAM_RESULT 退到桌的空镜头，UI 另挂

可走区（碰撞）：地面 U 形，宽约 220 px。不可走：柜体、桌芯、榻面、窗台、门槛外。

交互半径（圆心在道具热区中心，圆形，开发按此挂 `Area2D`）：

## 3. 镜头表

全部 16:9。命名锁定，方便截图脚本与 `Camera2D` 节点同名。

### Steam 商店五张（构图锚点）

| 镜头 | 用途 | 画内必有 | 裁掉 | 备注 |
| --- | --- | --- | --- | --- |
| **CAM_HERO** | 第 1 张 / 胶囊同构图 | 门洞、坐堂桌、脉枕、病人椅、百子柜至少 4 列、花窗药圈条、一束窗光落在脉枕 | 天花以上、门槛以下、柜的最右一列可切半 | **禁止空山水**。视觉重心是「厅堂 + 一只按在脉枕上的手」，手可以是学徒的，不必等角色定稿也可先用剪影占位 |
| **CAM_ASK** | 第 2 张 问诊 | 病人 3/4 侧、上半身、一张嘴在说话（表情含糊，不报病名）；桌沿、一角香炉烟 | 整面药柜、针灸榻、门 | 对话框由 UI 组挂；场景只留病人右上约 360×200 的干净宣纸空 |
| **CAM_PULSE** | 第 3 张 **必进前三** | 脉枕占画幅下 1/3；腕横在枕上；三指（寸关尺）位置留空给美术的脉象层；窗2光从画面左上扫到枕面 | 全身、柜、门 | 场景只提供**空间框和光**。脉纹、浮沉迟数动画是美工的事。枕面高光必须稳定，不能靠角色自发光 |
| **CAM_FORMULA** | 第 4 张·配药 | 打开的两排抽屉 + 调剂台 + 药研 + 戥子；柜仍可读成「同一栋」 | 门、针灸全身 | 药是拖出来的，不进菜单 |
| **CAM_NEEDLE** | 第 4 张·针灸（可与配药做左右两帧或同一镜头里远景带柜） | 榻、病人侧躺轮廓、可点的穴位点位层；远处仍能看见百子柜剪影 | 脉枕特写 | 证明两种治疗在同一建筑，不是切地图 |
| **CAM_RESULT** | 第 5 张 | 空坐堂：桌、枕、一缕香、窗光；病人已起身或出画 | 热闹道具特写 | 安静。分数 UI 由其他组覆盖中央偏上 |

### 玩法镜头（可从商店镜头微推）

- `CAM_HERO`：默认探索，轻微跟随学徒，死区 200 px，不出房间。
- `CAM_ASK`：问诊锁定，FOV 相当于 1920 世界宽裁到 1280。
- `CAM_PULSE`：再裁到约 960 宽，焦点 (脉枕中心)。禁止旋转、禁止 3D 绕腕。
- `CAM_FORMULA`：焦点 (调剂台中心)，能同时看见被拉开的抽屉。
- `CAM_NEEDLE`：焦点 (榻中心)，穴位点在 1080p 上不小于 18 px。

推荐 `Camera2D` 位置（中心点，世界 px）：

```
CAM_HERO     (1280,  780)
CAM_ASK      (1100,  620)
CAM_PULSE    (1020,  640)
CAM_FORMULA  (1880,  860)
CAM_NEEDLE   ( 520,  900)
CAM_RESULT   (1280,  700)
```

## 4. Godot 2D 图层（从底到顶）

用 `CanvasLayer` + 一个 `YSort`（人物与家具底座），不要把角色塞进 Parallax。

| 序号 | 节点建议 | 画什么 | 滚动/排序 |
| --- | --- | --- | --- |
| L0 | `ParallaxBackground/paper` | 宣纸底：纤维、淡渍、无家具；暖纸 `#F7F0E4` | 静止，或 0.02 呼吸级污渍 |
| L1 | `arch` | 圆角柱梁门洞、北墙三樘花窗（中樘半开）。萌态，不肃杀 | 不 Y-sort |
| L2 | `yard_strip` | 窗后药圈条：白墙、三盆、碎石、一株叶 | 视差 0.15，**不可走** |
| L3 | `furniture` | 桌、椅、柜体、榻、调剂台 | Y-sort，原点在触地点 |
| L4 | `props_interact` | 脉枕、香炉、抽屉面板、药研、戥子、汤壶、穴位点占位 | 可点；抽屉为独立 Sprite |
| L5 | `YSort/characters` | 学徒、病人；脚底 y | 标准 Y-sort |
| L6 | `fx_light` | 窗2 → 脉枕的一束淡青光（不是霓虹） | 加法或 modulate 0.25 |
| L7 | `fg_wash` | 前景墨洗、一串悬药、半透明桌沿 | 盖角色肩以下，**不要挡住脉枕高光** |
| L8 | UI 组 | 对话、分数、免责 | 本包不画 |

抽屉拉开时：L4 的抽屉 Sprite 向玩家方向移 24–36 px，露出药堆（短墨点+淡彩），供拖拽。

## 5. 调色与材质

**画风：** Q 版可爱水墨（可爱水墨）。柱、梁、窗、桌、柜、榻全部圆角胖轮廓，大色块、剪影清楚，chibi-adjacent 厅堂（角色仍归美工）。软圆头墨线。不是写意文人、不是墨分五色厅堂、不是工笔写实、不是像素、不是照片木纹、不是霓虹。

**底：** 宣纸。暖纸 `#F7F0E4` 到旧纸 `#E7DCC8`。纤维用噪波。分层 PNG：`ui/layers/` 与副本 `scene-slice/layers/`。

**淡彩（铺在纸上，萌态厅堂）：**

| 色 | 用途 | 约值 |
| --- | --- | --- |
| 暖纸 | 宣纸底、留白 | `#F7F0E4` |
| 桃 | 桌面、枕、门扇浅染 | `#F3C4A8` |
| 薄荷 | 榻面、椅垫、窗后叶 | `#C5D5C0` |
| 天青 | 窗纸、窗2光束 | `#C9DCE8` |
| 朱砂点 | 枕边一线、印、炉星 | `#C45C4A` |
| 圆头淡墨 | 轮廓 | `#5A4A3C` |

**禁止：**

- 像素抖动、网格、16-bit 复古
- 霓虹 UI 光晕、描边发光技能特效
- 照片级木纹、PBR、油漆高光
- 空镜头山水当胶囊（山可以画在窗后一条里，不能当主画面）
- 写意文人 / 墨分五色厅堂 / 工笔院体
- 墙上经络图当交互；柜格只写药名，不写功效
- 现代不锈钢、玻璃柜台、荧光灯管（参考图里有，那是布局不是风格）

柜门、桌面、脉枕的「高光」用留白，不用白闪点。

## 7. 药圈如何简化（仍要进英雄镜头）

**不做**第二张地图、不做出门采药循环（那是一期）。

做成北墙一条，厚度约 **120 px 世界高**：

1. **室内窗台：** 三只陶盆（叶色用草青点染），不可走、不可采。切片里点了只触发「望」的一句环境观察（文案剧本组写，不写功效）。
2. **窗格：** 三樘，中樘（窗2）半开，是全屋唯一定向光源。
3. **窗外条：** 白粉墙、碎石、一株，漏窗可再透一层更淡的叶子。全部画在 L2，视差 0.15。
4. **英雄镜头：** 药圈只占画面上沿 12–18%。让人读出「这是医馆后面的小天井」，不是园林游记。

参考：`ref-courtyard-window.jpg`（从暗室内看亮庭）、`ref-penjing-pots.jpg`（盆的体量，只取 2–3 盆的密度，不要整园）。

## 8. 日光

全天固定，无昼夜。

- 环境：柔和室内。没有硬影。圆角家具用淡彩分远近，不用焦墨把厅堂压成文人画。
- **唯一定向光：** 窗2 → 斜向南落在脉枕布面和病人腕。光斑椭圆约 180×90 px，色为极淡天青 `#C9DCE8`+纸色，multiply 或 overlay，强度低。不是霓虹。
- CAM_PULSE 必须能看清枕面高光；如果角色袖口挡住光斑，改袖，不改光。场景只给枕面+窗2光，**不画脉纹 / 寸关尺波形**（那是美工 `pulse-overlay.png`）。
- 香炉火是朱砂针尖，不照亮房间。
- 悬药、梁底用圆头淡墨，把眼睛压回桌面；中下脉枕区域保持干净。

- 真实医疗建议、功效墙、百科

### 场景块（本包锁死、开发按此摆）

- 拖药：从抽屉中心到调剂台，吸附半径 40 px。
