## 1. 一句话

处治选食疗 → 膳盏拖 1～3 张教学食材卡（可加一句起居劝说）→ 结算；可从侧桌茶灶进，也可纯 UI。

---

## 2. 推荐路径（主）：纯 UI

与开方托盘同级：点 `ACTION_FOOD` → 全屏/半屏膳盏层 → 交卷 `settle("food", …)` → 回诊室。

| 镜头 | 中心 | 用途 |
| --- | --- | --- |
| `CAM_FOOD` | **(1280, 700)** 或沿用 `CAM_RESULT` | 安静坐堂；膳盏盖 UI，不必新 World |
| 退出 | 回进入前相机（多为 `CAM_HERO` / `CAM_ASK`） | |

### UI 位框（1920 设计宽）

```
顶栏：四诊 / 处治钮（ACTION_FOOD 与开方、针灸并列）—— 膳盏层勿遮顶栏
┌──────────────┬─────────────────────────────┐
│ 卡池 6 张     │  膳盏（中心碗）1～3 槽        │
│ 竖列或环碗    │  可选：劝说 3 选 1            │
│              │  [提交食疗]                   │
└──────────────┴─────────────────────────────┘
```

| 区 | 建议 |
| --- | --- |
| 膳盏 | 舞台中央偏下，碗直径约 280～320 px；吸附半径 40（对齐药托盘手感） |
| 卡池 | 左列宽 200，或环碗六向；图标 72～96 |
| 劝说 | 右列三卡，单选；不选可交 |
| 避让 | **不挡** 望闻问切顶行；不挡返回 |

## 3. 可选路径：诊室侧桌 / 茶灶热区

给「用手摆碗」进场感；点后仍打开同一膳盏 UI。

| ID | 位置约 (x,y,w,h) | 半径 | 说明 |
| --- | --- | --- | --- |
| `Area_茶灶` / `STATION_FOOD` | **(1480, 520, 200, 180)** | 90 | 坐堂桌东侧、百子柜西沿之间的侧桌+小茶灶；暖木小炉+碗 |

避让（勿重叠）：

| 已锁 | 位置 |
| --- | --- |
| 脉枕 | ~(920, 600)` 一带 |
| 病人椅 | `(1040, 590)` |
| 调剂台 | `(1720, 780, 400, 180)` |
| 针灸榻 | `(240, 780, 480, 200)` |
| 次日开馆 HUD | 右下 |
| 阁楼入口 | 北墙梯口 |

热区仅在 `treatment_choice` / 处治可选时高亮；idle 可灰。

切入时可微推 `CAM_FOOD`：**(1500, 620)**（侧桌特写），打开 UI 后也可切回 `(1280, 700)`。
