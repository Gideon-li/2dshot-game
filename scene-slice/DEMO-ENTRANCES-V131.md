## 1. 原则

1. 每个子场景入口在诊室有 **世界木牌或门楣字**（2～4 字）+ 热区；HUD checklist 可再点同一 handler。
2. 引导日（`play.demo_guide` 开）入口 **常亮轮廓或小印「可去」**；时辰未到则灰 + 一句原因（逻辑），木牌仍可见不隐藏。
3. 标签用生活向：药圃 / 炮制 / 阁楼 / 次日；**不要**功效、诊断、百科墙。
4. 返回：子场景门回诊室空闲；返回不挡存档（角色开发）。

## 3. 门牌规范（美工 / 场景）

| 项 | 锁 |
| --- | --- |
| 尺寸 | 木牌约 72×36～96×48 px（世界），字 2～4 个 |
| 对比 | 暖木底 + 深墨字；引导日可加淡金描边或小印「导」 |
| 位置 | 挂在门楣/门栓旁，**不挡住** 脉枕、病人椅、四诊 HUD、调剂台中心 |
| 灰态 | 时辰未到：牌仍在，半透明或挂「入暮」「入夜」小角标（美工） |
| 多语言 | 世界牌可用中文；HUD checklist 走 i18n `DEMO_*` |

---

## 4. 引导日推荐发现序（与 checklist 对齐）

1. 诊室坐堂（南门/候诊）— 已有  
2. 处治后 → 高亮 **药圃** 牌  
3. → 高亮 **炮制** 牌  
4. → 高亮 **阁楼** 牌  
5. → **次日开馆** 右下钮 + 南门木牌  

同屏不要同时闪超过 **2** 个入口高亮（防噪）；当前推荐步用描边，其余牌静默可见。
